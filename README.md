# Reliable Cleaning Service

Static HTML, CSS and JavaScript site. Each page has its own HTML file and readable content without JavaScript. GSAP ScrollTrigger drives the illustrated night shift.

Run locally with `python3 -m http.server 8080`. No package installation or build step. Deploy from this root with Vercel, framework set to null.

The admin is at `/admin/`. Quotes and edits use localStorage in the same browser, on the same origin. Nothing is submitted to a server. Notification email is a future live-site setting only.

Source copy: `client-media/reliable-site-2026-09-30.md`. Generated artwork and prompts: `assets/generated/MANIFEST.md`.
